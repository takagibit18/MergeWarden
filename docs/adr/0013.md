# ADR-0013 · 可恢复图 generation 与严格停止

状态：稳定性层已实施；实体图语义层见 ADR-0014

日期：2026-09-22

## 背景

旧图在内存中积累全仓语法事实，超过总量上限时在任何持久化之前失败；`building`、`incomplete` 和 `error` 缓存会在下次查询时重新全量构建。已发布 SQLite 同时保存整文件 facts JSON 与拆分记录，并在每次 worker 请求时重新打开、全表摘要校验。审查取消还会无界等待 runtime abort 与工具队列。

## 决策

图缓存身份绑定 snapshot、schema、parser、resolver、范围策略和资源预算。提取结果按完整文件提交到独立 checkpoint SQLite；checkpoint 只用于恢复，绝不回答查询。解析和完整性校验通过后，构建器生成不可变 generation SQLite，刷盘后用原子替换的 `published.json` 切换。`ready` 表示声明范围完整；容量、解析或文件缺口只能发布带覆盖信息的 `partial`。游标绑定 generation，不能跨发布版本继续。

确定性容量失败按完整缓存身份记录，不自动重复；临时 I/O、锁冲突与取消不永久缓存。每个身份使用单 builder lease，并发请求明确收到 `building`。损坏的已发布 generation 只隔离一次，再从 checkpoint 有界恢复。

一个 review 内复用一个可终止 worker、只读 generation 句柄及检索索引。V8 `maxOldGenerationSizeMb` 只作为 JS heap 限制，不再描述为进程总内存硬上限。

审查工具预算在接纳时扣减，分别记录 requested、accepted、executed、rejected。deadline、显式取消或预算耗尽会关闭工具接纳、拒绝未执行队列、终止图 worker，并只在有界时间内等待 provider abort 与在途工具。Pi 的真实 session abort 与外部监督同时保留；本地停止不声称能够证明供应商停止远端计费。

## 安全与发布边界

构建只读取不可变 SnapshotStore 文本，不执行目标仓库模块、安装脚本或测试。checkpoint 的存在不表示图可查询；外部 manifest 只指向通过 SQLite 事务、外键、计数和 quick-check 的 generation。新 generation 发布失败不会把 staging 冒充成图，也不会覆盖 manifest 当前指向的有效 generation。

## 来源边界

generation/checkpoint、失败缓存、范围覆盖、changed-file 优先、SQLite 发布协议和严格停止均为 MergeWarden 工程扩展，不属于 LocAgent 论文或其官方实现。

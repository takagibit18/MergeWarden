# ADR-0014 · LocAgent 风格实体图与分层范围

状态：已实施；真实仓库容量已测，审查质量增益未证明

日期：2026-09-22

## 背景

旧图以 module/class/function/method 加普通 reference site 为中心。普通名称引用数量大、语义弱，最终 SQLite 又同时保存整文件 facts JSON 与拆分后的记录，图规模随源码快速膨胀。全仓 Python 默认范围还把测试、示例、benchmark、生成代码和 vendor 混入主要导航图，使“完整构建”与“对审查最有用的范围”难以区分。

LocAgent 论文和固定源码提交 `4935b557326c154bad8e8dcf3747cc8d32d1f387` 提供了 directory/file/class/function 实体层级、contains/imports/invokes/inherits 关系和多跳实体导航的参照。其代码使用 Apache License 2.0。本项目没有搬运其图构建代码；只按固定来源核对机制，并保留 MergeWarden 的不可变快照、Tree-sitter 事实、保守解析和源码证据边界。逐项来源、许可、适配状态与证据位置见 `eval/locagent/entity-graph-v4-fidelity.json`。

## 决策

对外实体类型固定为 `directory`、`file`、`class`、`function`。Python method 归入 function，并用可选 `functionKind=method` 保留诊断信息。文件是模块实体，目录由规范化仓库相对路径合成；`CONTAINS` 形成 directory → file → class/function 层级。

可遍历关系只保留 `CONTAINS`、`IMPORTS`、`CALLS`、`INHERITS`。普通名称引用不再构图，也不建立 reference 索引；需要普通文本引用时使用 `search_text`。CALLS 与 INHERITS 只接纳词法作用域或显式 import alias 可唯一证明的目标。动态 receiver、通配 import、条件/重复定义、外部依赖和不完整语法仍保留为有来源范围的 dependency site，但不会成为可遍历关系。禁止按全仓同名回退补边。

构图使用两遍流式解析：第一遍只索引声明、作用域、绑定和 import；第二遍按文件解析 dependency site 并提交 relationship checkpoint。最终 schema v4 只保存查询所需的文件元数据、实体、dependency site、聚合关系和逐 site 来源；不保存整文件 facts 或通用 payload。重复的同一 source/target/kind 关系合并为一条并记录 `site_count`，`relation_sites` 保留每个源码位置。

默认 `core` 范围始终包含 changed Python，并包含生产代码；未变更的 test、example、benchmark、generated、vendor 文件按可审计分类排除。路径规则以完整 component 为主；范围策略 v2 另记录一个精确例外：源码头声明自动生成的 SymPy `integrals/rubi/rules` 树归为 generated，但普通 `rules/` 目录不受影响。显式 `scope=all` 使用独立缓存身份构建补充图。范围缺口、解析不完整和容量省略继续导致 `partial`，空查询不能证明全仓不存在关系。

## 兼容与迁移

schema 升为 v4，resolver 升为 `python-entities-streaming-5`，范围策略升为 `python-core-scope-2`，并与资源预算一起进入缓存身份。schema v2/v3 generation 和旧 resolver checkpoint 不迁移、不复用；首次请求按新身份重建。`core` 与 `all` 互不覆盖，旧历史评测及其 fidelity 文件保持原版本含义。

发布协议沿用 ADR-0013：checkpoint 不可查询；只有事务、外键、计数、范围和 SQLite 检查通过的不可变 generation 才能由原子 manifest 发布。解析中止、关系容量失败、锁竞争或 worker 终止不会发布 staging，也不会替换其他有效身份的 generation。

## 已知限制

本阶段只支持 Python head snapshot；没有 receiver 类型推断、MRO/动态继承解释、高级 import loader、namespace/src-layout 自动搜索根或跨 snapshot 增量更新。`__init__` 保持普通 function 实体；类调用指向 class，不伪造到构造函数的 CALLS。多跳遍历有循环、节点、边、深度和字节上限。

大仓库构建、存储、查询、分层差异和观测内存数据见 `docs/VALIDATION.md`。这些测量证明工程容量与可审计退化，不证明 Graph 提高代码审查质量。

# ADR-0003 · Pi runtime 与集中业务 Controller

状态：已确定（底座）；接入待联调

日期：2026-09-20

## 背景
避免第二套 harness 和分散 Hook 状态；当前官方 SDK 名称见 sources。

## 决策 / 当前建议
Pi 负责模型循环、工具执行机制、压缩与会话；Hook 仅转交边界检查，业务状态统一由 Controller 管理。

## 约束与代价
不 fork Pi；不把 agent_end 映射为 completed；执行阶段再次检查权限和状态。

## 验收
以 docs/ROADMAP.md 和 docs/VALIDATION.md 为准；状态更新必须保留历史原因。

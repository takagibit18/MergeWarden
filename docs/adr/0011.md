# ADR-0011 · 可复现开发仓库基线

状态：已实施（M0）；不表示 M1 产品闭环完成

日期：2026-09-20

## 决策

保留核心与两个 SDK 适配器的独立依赖边界。生成并提交三个真实 package-lock.json；统一 setup 使用 npm ci 并禁用生命周期脚本，verify 运行所有当前可执行验收。CI 覆盖 Windows/Linux、Node 22/24，所有测试均无需模型密钥。

Python grammar 使用官方 tree-sitter-python 0.25.0 发布包中的 WASM，记录 commit、MIT 许可证、SHA-256 和 ABI 15；先验证 bytes 再解析。未加入解析失败时的降级替代。

Pi smoke 验证真实 SDK、原生 JSONL 和分支重放，同时保留首条 assistant 前延迟写盘这一已观测限制。测试中的 assistant 为 synthetic fixture，不能用于模拟生产持久化保证。

原始 DOCX / 同源 Markdown / design-source.json 保留输入骨架历史内容；最新能力由 IMPLEMENTATION_STATUS 和 VALIDATION 明示，避免把原方案改写为已交付产品。

## 范围

用户本次确认本地仓库搭建及 GitHub 远程仓库创建。默认私有；不擅自决定公共许可证、IDE 产品入口或发布功能。

## 后续

按 M1 完成固定快照、只读工具、Pi 业务绑定及报告可靠落盘；独立处理首次回复前持久化和写入故障恢复。

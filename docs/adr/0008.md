# ADR-0008 · 不可变快照与版本化证据

状态：建议采纳；核心已有契约

日期：2026-09-20

## 背景
PR 与 IDE 都会发生版本漂移；仅记录路径和行号不够。

## 决策 / 当前建议
每个 run 固定 repository/base/head/input/config；每个证据指明 base/head 与 hash。每个图实例对应一个不可变源码快照。

## 约束与代价
暂存、磁盘、未保存缓冲区严格区分；恢复和展示均校验版本。快照 provider 仍未实现。

## 验收
以 docs/ROADMAP.md 和 docs/VALIDATION.md 为准；状态更新必须保留历史原因。

# ADR-0002 · 真实语法分析与可核验代码关系

状态：v0.2 Python 全量图、显式 resolver 和 SQLite 查询已实现；质量增益尚未证明

日期：2026-09-20

## 背景
用户要求 AST + Tree-sitter；骨架提供真正解析起点，不伪装完整图服务。

## 决策 / 当前建议
使用 Tree-sitter CST -> 统一 AST/语法事实 -> 作用域/导入解析 -> 可查询图。禁止正则替代、执行 import 或仅靠同名连边。

## 约束与代价
Python 首先支持是骨架建议。SQLite 是存储草案。调用边的 candidate/unresolved 状态必须保留。

## 验收
以 docs/ROADMAP.md 和 docs/VALIDATION.md 为准；状态更新必须保留历史原因。

## v0.2 实现边界

当前实现见 [状态](../IMPLEMENTATION_STATUS.md) 与 [解析器说明](../../integrations/tree-sitter/README.md)。稳定性层已迁移到 Graph schema v3 / resolver python-scopes-2，仅索引 immutable head；本阶段仍保持 CONTAINS、IMPORTS、REFERENCES、CALLS 语义。candidate/unresolved 不生成可靠 CALLS；每次查询附带覆盖范围和限制。checkpoint 不可查询，只有校验并原子发布的 ready/partial generation 可以查询。实体粒度与关系集合的下一次迁移不回写此阶段验证结果。

# ADR-0004 · 原生 JSONL 与恢复边界

状态：已确定（持久化方向）；强保证待验收

日期：2026-09-20

## 背景
用户要求 JSONL；不另造会话消息日志。

## 决策 / 当前建议
生产业务事件使用 Pi CustomEntry，默认不加入模型上下文；图索引与最终 artifact 分开存储。

## 约束与代价
仅重放当前分支、核对 input/config/base/head；append 返回不等于 fsync。骨架 MemoryJournal 只用于测试。

## 验收
以 docs/ROADMAP.md 和 docs/VALIDATION.md 为准；状态更新必须保留历史原因。

## M0 联调记录

Pi 0.84.1 的 JSONL 重开和当前分支重放已通过真实 SDK smoke；首条 assistant 前可能不创建文件，append 不表示可靠落盘。强恢复仍待 M1，见 integrations/pi/README.md 和 ADR-0011。

## v0.1 后续

已通过公开 SessionManager.open 与独占空文件实现首条回复前落盘；持久化失败终止和交付清单门槛见 [ADR-0012](0012.md)。M0 发现保留为历史原因，现有实现及实测以 IMPLEMENTATION_STATUS/VALIDATION 为准。

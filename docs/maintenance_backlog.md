## 文档维护规则

- 当前行为放契约或使用指南；理由与被放弃的方案放[设计记录](design_decisions.md)。
- 完成的一次性执行计划回到 Git 历史，未完成事项给出明确证据和关闭条件。
- 历史评测报告写明日期、配置及适用范围，不作为当前生产或 CI 默认值来源。
- [错误记录](error_log.md)保留独有排障证据；新增记录只收录可复用根因、影响和验证，不追加整段工具输出或重复交付流水。
- 阈值以现行评测配置为准，CI 实际执行项以工作流为准；不从旧 roadmap 复制数字。

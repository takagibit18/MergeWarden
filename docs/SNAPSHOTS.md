# 快照模块

引擎在真实仓库根目录冻结输入，内容放在独立 state 目录。`SnapshotStore.freeze` 提供提交比较、index 和已保存 worktree 三种输入；工具始终从不可变内容存储读取。该模块本身不调用模型。

- 提交两端记录真实 SHA；index/worktree 记录内容版本。不同提交即使树内容相同也不会混用证据身份。
- Git 对象批读，工作区两次捕获并检查 HEAD/index，发现竞争修改则拒绝。
- 未跟踪文件须显式指定，忽略文件拒绝纳入。中文文件名、删除/重命名及部分暂存有回归测试。
- 源码原始 UTF-8、BOM 和换行保持不变；行范围证据使用返回文本的 SHA-256。
- 符号链接/子模块/二进制/超大 Git 文件明确不支持文本取证；工作区路径中的符号链接拒绝读取。
- 超限、截断、版本不符、内容修改、覆盖清单修改均不会当成完整成功。

单文件 1 MiB、最多 10,000 路径和 100 MiB 捕获内容。差异采用线性前后缀裁剪的合并替换块，分散改动可能在同一块内；不声称 Git 最小 diff，也不执行外部 diff 驱动。

验证：`node --experimental-strip-types --test tests/snapshot.test.mjs`。首次真实模型门槛、运行日志与报告交付由后续引擎模块负责。
